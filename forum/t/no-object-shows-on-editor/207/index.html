valentin
Dec '15

I have the feeling there is something wrong with your Arduino Yun and it is sending wrong data to the Reality Editor. The consequence is that the Reality Editor generates an error and stops the entire Javascript GUI.
When you are in airplane mode, the data will not be received and there is no error.

This would be an interesting case for debugging.
So with the following steps, when you reach the delete step, you can also make a backup first and send me the object.json files that you can find in each object folder.

Can you try the following:

  1. Put the Arduino SD-Card in your computer and go to the folder:
    SD-Card/HybridObjects/objects/

  2. Delete all objects in that folder (this is where your HTML interface is stored).

  3. Now reload the Developer Webpage and Add a new slider object.

  4. Upload the example.

  5. Programm the Arduino.

  6. Push the 32U4 Reset button on the Arduino yun.

  7. And restart your Reality Editor.

  8. You should now be able to see it.
